Raspberry Pi build and run commands
====================================

First time only:
chmod +x scripts/*.sh

Normal modes:
./scripts/run_rpi.sh --test
./scripts/run_rpi.sh --hardware can0 125000
./scripts/run_rpi.sh --production can0 125000

Phase 2 feature demos:
./scripts/run_rpi.sh --sabbath
./scripts/run_rpi.sh --maintenance

The run script builds the matching configuration automatically when it is
missing. To build without running:
./scripts/build_rpi.sh --test
./scripts/build_rpi.sh --hardware can0 125000
./scripts/build_rpi.sh --production can0 125000
./scripts/build_rpi.sh --sabbath
./scripts/build_rpi.sh --maintenance

Feature modes can also use real CAN:
./scripts/run_rpi.sh --hardware can0 125000 --sabbath
./scripts/run_rpi.sh --production can0 125000 --maintenance

Sabbath uses a 10-second stop timer. Maintenance starts with a demo request
to floor 2. Edit the matching build-rpi/*/demo_control.txt before running if
you need a different demo value.

Audio files belong in audio/floor1.wav, audio/floor2.wav, and audio/floor3.wav.
miniaudio.h is included in include/, so deployment does not depend on the
developer's Downloads folder. Logs are written beside this file.
